## 2. 미래를 본 뒤 정책을 다시 고르지 않는다

1. 동일 분류 원문·Feature·Config·재고·공급·Forecast에서 각 32/32/88개 후보를 실제 수학 전략→Guard→PSI로 실행한다.
2. Source 전체를 같은 입력으로 재실행해 검증하고 기존 선택기로 품목별 정책을 고정한다.
3. 세 방법의 선택 Hash를 모두 고정한 **뒤에만** 새 평가 수요의 88개 PSI를 계산한다.
4. 고정 정책의 의미 키 `(종류, RMOS, EMOS, 서비스 설정값, 검토주기)`로 평가 PSI를 찾는다.
   Candidate ID가 달라지는 출처 차이를 정책 차이로 오해하지 않는다. 평가 구간에서 선택기를 호출하지 않는다.
5. 미선정 품목은 Baseline과 원 미선정 사유를 보존한다. 실패 후보를 성공 Baseline 정책으로 위장하지 않는다.

새 평가 수요를 Canonical Forecast 수량 칸으로 재생한 **합성 실적 Replay**다.
확정 고객주문과의 동일 주차 수요 소진 규칙, 주문 생성 이후 상태 피드백, 납기·제약은 그대로 적용한다.
정책의 수량 행동은 상태에 따라 달라질 수 있지만 정책 매개변수·선택은 바뀌지 않는다.
원 분류/Config·Canonical/Prepared/Mathematical Hash와 Gate Hash, 공통 정책의 실제 PSI Row/지표를 방법 간 대사한다.

## 3. 무엇을 비교하는가

- 서비스: 실제 PSI의 현재 수요 수량 충족률과 종료 고객 BO. 설정 CSL을 달성 서비스로 표기하지 않는다.
- 비용·재고: 동일 서비스 자격을 모두 만족한 품목 쌍에서 비용·평균 주차말 On-hand를 비교한다.
  미선정 Baseline까지 포함한 전체 비용은 설명용이며, 값이 낮다는 이유로 우수하다고 판정하지 않는다.
- 좋은 후보: 88개 안에서 서비스 적격 후보 중 `(비용, 평균재고, 발주횟수)` 최저 동점 집합이다.
  마지막 Candidate ID 동점 해소는 이 집합 정의에서 제외한다. 전체 탐색 공간의 진짜 최적해를 뜻하지 않는다.
- 누락: 계획 시점 좋은 후보의 포함 여부/재현율과, 새 수요를 본 후 알게 된 참조 좋은 후보의 범위 누락을 구분한다.
  참조에는 서비스 적격 후보가 있는데 고정 선택이 미달한 경우는 별도 ‘실현 서비스 기회 누락’으로 남긴다.
  참조에도 적격 후보가 없으면 좋은 후보 비교의 분모에서 제외하며 실패를 성공으로 바꾸지 않는다.
- 시간: 후보 실행과 전체 Source 재실행 검증·선정을 포함한다. 공통 분류/Feature 준비·평가용 88개 Replay·
  Artifact 저장/재시작 검증은 별도 측정한다. 3회 중앙값은 한 Mac의 기술 측정이며 통계적 우월성 검정이 아니다.

좋은 후보를 모두 담은 좁은 범위도 여러 동점 후보의 개수는 적을 수 있다.
따라서 ‘좋은 후보 1개 이상 포함’과 ‘전체 동점 후보 재현율’을 혼동하지 않는다.
공통 분류 준비에는 ABC와 Legacy Feature를 모두 계산한다. 이번 시간 비교가 ABC/Legacy 분류 자체를 생략한
Runtime의 성능 비교는 아니며 **후보 범위 차이**를 평가하는 것이다.

### 품목별로 해석해야 할 점

- **간헐·고가 품목은 두 기간 모두 세 방법에서 서비스 미달**이다. ABC 수량 충족률은 A 88.83% / B 76.13%,
  Legacy·참조는 A 72.87% / B 61.26%다. 참조 88개 안에는 새 수요의 적격 정책이 있었지만,
  계획 Forecast에서 고정한 선택은 이를 고르지 못했다. 넓은 범위만으로 미래 서비스가 보장되지 않는다.
- 안정·단기 LT는 세 방법의 실제 비용·재고가 같았다. 안정·장기 LT와 변동·지역 LT의 공통 적격 4건에서
  Legacy의 비용·재고가 더 높았다. 이번 설정에서 Legacy가 더 좋은 후보를 고른다는 근거는 나오지 않았다.
- ABC는 계획 최저 성과 동점 집합을 더 자주 놓쳤는데도 새 수요의 서비스·비용은 더 나았다.
  **계획 Forecast에 대한 최저 비용 후보 포함률과 미사용 기간의 성과는 다른 지표**다.
  참조 88개에 대한 최적성도 미래 최적성은 아니다.
- 종료 고객 BO는 모두 0이지만 Forecast 부족은 남는다. 고객 BO가 없다는 사실만으로 서비스 성공이라고 판단하지 않는다.

## 6. 한계와 후속 판단

두 합성 창·8 품목·기간만으로 방법의 운영 우월성이나 ML 필요 여부를 일반화하지 않는다.
실제 수요 이력·수요 검열·지연 입고·공동 발주비·기간 말 효과는 추가 검증 대상이다.
특히 49일 LT는 13주 평가에서 종료 편향이 크다. 결과를 본 뒤 이번 기간을 늘리거나 비용을 조정하지 않고,
필요하면 별도 사전 고정된 장기/비용 민감도 실험으로 확인한다.
Forecast 부족을 고객 BO로 이월하거나 별도 판매기회손실 비용으로 과금하지 않는 기존 PSI·비용 계약을 유지한다.
