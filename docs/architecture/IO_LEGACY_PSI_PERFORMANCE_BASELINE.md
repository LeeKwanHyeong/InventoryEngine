# C# Release·Python 재현 기준의 실제 PSI 성능 비교

2026-10-21 · InventoryEngine `inventory_engine_dev`, HEAD `99f2f12`와 기존 미커밋.
**상태: 측정·전체 결과 대조 완료 / 최적화 없음.**

## 1. 결론

현재 최적화 전 Python 재현 기준은 같은 입력·자원·출력 조건의 C# Release보다 느렸다.
16품목 × 32후보 × 52주에서 계산 중앙값은 C# **1.390ms**, Python **141.220ms**다.
직렬화·Hash·비교용 파일 저장을 포함한 반복 1회의 중앙값은 **9.237ms / 161.743ms**다.
각각 Python 소요시간이 C#의 **101.59배 / 17.51배**이며, 속도 개선으로 기록하지 않는다.

이는 **같은 결과를 내는 현재 두 구현**의 비교다. 언어 자체의 순수 속도비나 운영 DSIO 전체의 처리시간이 아니다.
Python 진단 구현의 frozen 결과 생성·교체, 유한 수치 검증 등 추가 비용도 계산에 포함한다.
그 비용의 기여도를 분리한 프로파일링이나 알고리즘 최적화는 아직 하지 않았다.

## 4. 반복 횟수와 시간 구분

- 먼저 두 언어·두 입력 규모의 사전 검증 4회를 실행해 전체 결과가 같은지 확인했다.
- 조건별로 **새 프로세스 3회**, 각 프로세스에서 최초 호출 1회 → Warm-up 3회 → 본측정 7회를 수행했다.
  따라서 조건별 본측정은 **21개**, 전체 본측정은 **84개**다.
- 언어 실행 순서는 프로세스 차수별 C#→Python / Python→C# / C#→Python으로 교차했다.
  강제 GC나 GC 비활성화, 표본 제외·최솟값 선별은 하지 않았다.
- 중앙값·nearest-rank 표본 P95·최소/최대·표준편차를 기록했다. 적은 표본의 P95를 운영 SLA로 해석하지 않는다.

| 구간 | 포함한 작업 |
| --- | --- |
| 입력 준비 | 각 새 프로세스의 입력 읽기·Hash·파싱·재사용 가능한 요청 DTO 생성 |

입력 준비와 최초 호출은 본측정 중앙값에 섞지 않았다. 각 구간 중앙값의 합과 전체 중앙값은 다를 수 있다.

## 6. 전체 결과 동등성과 저장 증적

JSON 숫자 표현 차이를 제거하기 위해 **측정 전 고정한 비교 전용 Binary 형식**을 양쪽에서 사용했다.
Header는 `<8s32siiii`, Row는 `<iiiii14d`다. 단순 Hash나 집계값만 저장한 것이 아니라 모든 PSI 행을 저장했다.

- Header에 실제 입력 Hash·행수·품목/후보/주차 수를 담는다.
- 전체 행에 수요·입고·BOH·EOH·BO/누적 BO·누적 PO·PO·할당량·할당률·ExpMOS·ROP·OUTL,
  발주/도착일을 담는다. 입력 Calendar와 각 행의 주차 위치로 날짜를 연결한다.
- 최초 호출·Warm-up·본측정·사전 검증을 포함한 **136개 파일**, 총 **1,923,584행**을
  건수·길이·SHA-256·전체 바이트로 검사했다. 불일치 **0건**이며 허용 오차가 없다.
- 1품목 파일은 **219,704 bytes**, 16품목 파일은 **3,514,424 bytes**다.
  대응 조건의 C#·Python과 모든 반복은 파일 크기와 Hash가 같다.
- 실제 발주 양수 행은 1품목 **442행**, 16품목 **6,948행**이며 누적 BO 양수 행은 **2행 / 7,354행**이다.
  상수·빈 결과만 계산한 시험이 아님도 확인했다.
- 총 Binary 보존량은 **253,920,704 bytes**다. 원본 파일은 전용 임시 실행 폴더에 보존했고 Git 산출물에는 넣지 않았다.
  해당 폴더가 삭제되면 Binary는 다시 실행해 만들어야 한다. 문서·원시 측정·입력·Source 지문은 저장소에 보존한다.

1품목 Payload SHA-256: `8bec8190823c6eafd525220c6b1c2100a30ad5728d6fd1049ae518c949da0ebe`.
16품목 Payload SHA-256: `13f50b6ffcf5294cd6ebc21368bf25634d198ad8ddd37698ff9c5208b5101ec7`.

[원시 측정 기록](evidence/legacy-psi-benchmark-results-20261021.json)에 모든 표본·명령·런타임·파일 지문을 남겼다.
기록에서 통계를 다시 계산하고 보존된 136개 파일도 재검증했다.

## 7. 주장하지 않는 것과 보존 경계

- 비교 전용 Binary 저장은 운영 JSON/Parquet Artifact Writer·Outbox·Receipt·DB 게시가 아니다.
  디렉터리 fsync·실제 DB I/O·장애 복구·전원 장애 내구성은 측정하지 않았다.
- 분류·후보 생성·서비스 집계·최종 정책 선택·ERP 발주 연계 속도는 제외했다.
  기존 개선형 Python이나 운영 배포 DSIO 전체의 속도로 인용하지 않는다.
- 기존 개선형·별도 재현 계산 2파일·FSN·운영 Gate·DB·공용 Runtime을 변경하지 않았다.
  새로운 캐시·벡터화·JIT·병렬화·계산 생략을 넣지 않았다. Commit·Push·배포도 하지 않았다.
